# JScript Engine (`jscript`)

The `jscript` package provides an ECMAScript 5 parser, Abstract Syntax Tree (AST), and compiler/runtime engine designed for Classic ASP JScript compatibility.

## Features

- **ECMAScript 5 & JScript Semantics**: Accurately reproduces Microsoft JScript behavior, object models, prototypes, and scope semantics.
- **AST Architecture**: Implements lexical parsing and AST-based transformation for JScript execution within AxonASP.
- **Interop with AxonVM**: Bridges JScript runtime objects and functions seamlessly with ASP intrinsics and native host objects.
