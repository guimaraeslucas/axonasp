# AxonASP TestSuite (`testsuite`)

The `testsuite` package provides automated test runners and benchmarking harnesses for executing Classic ASP integration test suites.

## Features

- **ASP Test Execution**: Discovers and runs automated ASP test scripts located in directories such as `www/tests/`.
- **Assertion & Reporting**: Validates script output against expected outputs, measuring execution times, error cases, and regression coverage.
- **Continuous Integration Ready**: Emits test results in standard formats suitable for CI/CD pipelines.

## Target Binary

Compiles into `./axonasp-testsuite.exe`.
