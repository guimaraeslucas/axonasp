# AxonASP MCP Server (`mcp`)

The `mcp` package provides a Model Context Protocol (MCP) server implementation for AxonASP.

## Capabilities

- **Documentation Integration**: Indexes, reads, and serves documentation and manual pages from `www/manual/md/` to AI coding assistants and LLM agents.
- **Context & Guidance**: Offers structured access to AxonASP error codes, native libraries, configuration references, and ASP coding standards over standard MCP protocols.

## Target Binary

Compiles into `./axonasp-mcp.exe`.
